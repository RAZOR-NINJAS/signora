# `signora tui`

> [!INFO] Summary
> **Interactive Terminal UI Dashboard**. Launches a cyberpunk terminal interface featuring real-time system monitoring, camera device selector, recognition mode launcher, and live status metrics.

---

## 1. Syntax

```bash
signora tui
# or simply run signora with no arguments in a terminal:
signora
```

---

## 2. Interface Features
- **Mode Switcher**: Quick-launch ISL, ASL, Body Spatial, Words, Alert, Stream, or Game.
- **Hardware Telemetry**: Real-time CPU, RAM, and GPU accelerator loads.
- **Camera Device Matrix**: Live listing of available video inputs and loopback nodes.
- **Model Registry Status**: Verification status of weights and assets.

---

## 3. Keyboard Navigation
- `UP` / `DOWN`: Navigate menu options.
- `ENTER`: Launch selected mode.
- `d`: Run doctor diagnostic check.
- `q`: Exit dashboard.
